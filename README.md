# Burnaby Land Search Map

Interactive Leaflet map showing areas and sample vacant land properties within approximately 2 hours drive of Burnaby, BC. Intended for exploring options for camping and eventual tiny home or small dwelling use.

## Notes

- Prices and listings are examples from recent public data and may no longer be active.
- Always verify current zoning, ALR status, access, water/septic feasibility, and local bylaws.
- Mobile tiny homes and full-time RV living are generally not permitted as principal residences in BC.

Deployed as a static site.
